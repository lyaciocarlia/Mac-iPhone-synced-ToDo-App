# TodoSync

A simple to-do list app for iOS and macOS that syncs over the network. Add a
task on your iPhone and it shows up on your Mac, and vice versa. Works
offline — changes are saved on-device immediately and pushed to the other
device automatically once you're back online.

## How it works

- **Shared code** — `TodoCore` is a local Swift Package with the data model,
  local persistence, sync engine, and all the SwiftUI views. Both the iOS
  app and the macOS app are thin shells that just show `ContentView()` from
  this package.
- **Local-first storage** — every change (add, edit, check off, delete) is
  saved to a JSON file on-device immediately, so the app works fully offline
  and never loses data.
- **Sync backend** — [jsonbin.io](https://jsonbin.io) is used as the free,
  no-server-code-required storage API: the whole list is one JSON document
  ("bin") that both devices read and write. It's free for personal use, no
  billing info required.
- **Merging** — on launch, on becoming active, and whenever the network
  comes back, the app pulls the remote list, merges it with the local list
  (per-task "last write wins" based on when each task was edited), pushes
  the merged result back, and saves it locally. Deletes are tracked as
  tombstones so a delete made offline still propagates once you're back
  online.
- **Reachability** — `NWPathMonitor` (Apple's `Network` framework) detects
  when the device goes offline/online and triggers a sync automatically on
  reconnect.

## Project layout

```
project.yml            XcodeGen spec — generates the .xcodeproj
TodoCore/               Swift Package: models, sync, persistence, views
  Sources/TodoCore/
    Models/             TodoItem
    Persistence/        LocalStore (on-disk JSON cache)
    Networking/          NetworkMonitor, JSONBinClient
    Sync/               SyncEngine (merge + push/pull orchestration)
    Settings/           SyncSettings, KeychainStore
    ViewModel/          TodoListViewModel
    Views/              ContentView, TodoRow, SettingsView
  Tests/TodoCoreTests/  Unit tests for the merge logic
Apps/iOS/                iOS app target (App.swift only)
Apps/macOS/               macOS app target (App.swift + entitlements)
```

The `.xcodeproj` itself isn't checked in — it's generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`, which
keeps the project file out of source control and avoids merge conflicts.

## Setup

### 1. Generate the Xcode project

```bash
brew install xcodegen
cd TodoSync   # repo root
xcodegen generate
open TodoSync.xcodeproj
```

### 2. Set your signing team

In Xcode, select each target (`TodoSync-iOS` and `TodoSync-macOS`) →
**Signing & Capabilities** → pick your Apple ID/team. You can also change
`com.lyaciocarlia.todosync.ios` / `.macos` to your own bundle ID prefix in
`project.yml` if you like (then re-run `xcodegen generate`).

### 3. Create a free jsonbin.io bin

1. Sign up at [jsonbin.io](https://jsonbin.io) (free).
2. Create a new bin with the initial content `[]`.
3. Copy the **Bin ID** (shown after creating it) and your **X-Master-Key**
   (Account → API Keys).

### 4. Configure sync in the app

Run the app on both your iPhone (or iOS Simulator) and your Mac, tap the
gear icon, and paste in the **same** Bin ID and API key on both. That's the
only thing that links the two devices together — from then on, adding,
checking off, or deleting a task on one device shows up on the other the
next time it syncs (immediately if both are online).

## Notes

- The API key is stored in the Keychain, not UserDefaults.
- `jsonbin.io`'s free tier is meant for light, personal use — plenty for a
  single user's to-do list, not for a multi-user production backend.
- Swap `JSONBinClient` for another backend (e.g. CloudKit, Firebase) later
  without touching the UI — `SyncEngine` only depends on the small
  `fetch()`/`push()` contract.
